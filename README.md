# 🐍 Python - Desde 0

Repositorio con mis prácticas, ejercicios y apuntes personales realizados mientras aprendo **Python desde cero**. El proyecto recorre desde la sintaxis básica hasta la programación orientada a objetos, el manejo de archivos, la serialización, las interfaces gráficas y las bases de datos.

El objetivo de este repositorio es documentar mi proceso de aprendizaje, guardar el código de cada práctica y tener un histórico de mi evolución con el lenguaje.

---

## 📌 Sobre el repositorio

Este proyecto recoge ejercicios y ejemplos organizados por bloques temáticos, siguiendo una progresión lógica de aprendizaje. Cada carpeta contiene archivos independientes con ejemplos prácticos de los conceptos estudiados.

## 🛠️ Requisitos

- [Python 3.x](https://www.python.org/downloads/)
- (Opcional) Un editor de código como [VS Code](https://code.visualstudio.com/) o [PyCharm](https://www.jetbrains.com/pycharm/)
- SQLite, incluido en la biblioteca estándar de Python, para los ejercicios de `14_BBDD`

---

## ▶️ Cómo ejecutar los ejercicios

Clona el repositorio:

```bash
git clone https://github.com/EstebanRodriguezGutierrezDEV/Python---Desde-0.git
```

Accede a la carpeta del proyecto y ejecuta cualquier archivo de práctica con:

```bash
python ruta/al/archivo.py
```

Por ejemplo:

```bash
python 14_BBDD/03_CRUD.py
```

Los archivos `.pyw` de `13_Interfaces_Graficas` pueden ejecutarse con Python en Windows para abrir las aplicaciones gráficas sin consola.
